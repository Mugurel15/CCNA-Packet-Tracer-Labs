## Abstract
This repository serves as a centralized portfolio for laboratory exercises and practical configurations completed during the Cisco Certified Network Associate (CCNA) 1 curriculum. The objective of this collection is to document the implementation, verification, and troubleshooting of foundational network architectures using Cisco Packet Tracer.

## Curriculum Scope
The practical exercises within this repository cover the following technical domains:
* *Network Fundamentals:* Topology architectures, OSI and TCP/IP models, and cabling protocols.
* *Network Access:* Switching concepts, VLANs, and Layer 2 configuration.
* *IP Connectivity:* IPv4/IPv6 addressing, subnetting, and static routing.
* *IP Services:* DHCP, DNS, and basic network management protocols.
* *Security Fundamentals:* Device access control, password encryption, and port security.
